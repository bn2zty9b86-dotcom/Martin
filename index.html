Dónde correr esta app

Este archivo es autónomo (HTML/JS, sin servidor). Para escanear con la cámara del iPhone necesitás alojarlo con HTTPS:

1. Netlify Drop — app.netlify.com/drop, arrastrás este archivo y obtenés una URL https en segundos. Es la opción más simple.
2. GitHub Pages — subís el archivo a un repo y activás Pages. Gratis y estable para uso diario.
3. Vercel — vercel.com, deploy de un único archivo estático.

Los datos (planilla cargada y conteos) se guardan en el almacenamiento local del navegador de ese dispositivo, no se envían a ningún servidor.
